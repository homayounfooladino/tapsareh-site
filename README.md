# سایت تپصره — رابط کاربر

رابط سایت `tapsareh.ir`: همان صفحه‌ای که کاربر در مرورگر می‌بیند. با نکست ۱۶٫۴٫۶ و ری‌اکت ۱۹٫۳٫۱ ساخته شده و نسخهٔ همهٔ بسته‌ها در `package-lock.json` قفل است (`.npmrc`: `save-exact`).

خروجی فقط پرونده‌های ایستاست (`output: "export"`). روی اسپارک هیچ سرور نود یا نکست اجرا نمی‌شود: سرور پایتون موجود (`src/trial/serve.py` در مخزن `maliat`) پوشهٔ `src/trial/static_next` را نشان می‌دهد و همهٔ `/api/*` را خودش جواب می‌دهد.

## ساختار

| پوشه | چه چیزی |
|---|---|
| `src/app` | چیدمان صفحه، سبک‌ها (`globals.css`)، صفحهٔ ۴۰۴ و صفحه‌های خطا |
| `src/components` | `App` (منطق اصلی: پرسش پیش از ورود، مهمان، ورود، پرسش، پاسخ جریانی، تاریخچه)، `Sidebar`، `Composer`، `Turn` (پاسخ با منابع و بازخورد)، `Welcome`، `UsageMeter`، `Icon` |
| `src/components/dialogs` | ثبت‌نام پیامکی، کد پیامک، کد دعوت، قوانین، راهنما |
| `src/content` | همهٔ متن‌های صفحه (`copy.ts`) و متن قوانین (`terms.ts`) |
| `src/lib` | ارتباط با سرور (`api.ts`)، چیدن پاسخ (`answer.tsx`)، رقم فارسی، نوع‌ها |
| `src/fonts` | قلم وزیرمتن، محلی، با مجوزش (`OFL.txt`) |
| `dev` | سرور ساختگی برای آزمودن بی‌اسپارک، و ابزار نسخهٔ نمایشی |
| `tests/e2e` | آزمون مرورگری |

قرارداد صفحه با سرور: `API_CONTRACT.md`.

## ساختن و آزمودن

```
npm ci
npm run lint && npm run typecheck
npm run build        # خروجی در out/
npm run e2e          # سرور ساختگی را خودش بالا می‌آورد؛ ۷۳ بررسی
```

آزمون مرورگری پایتون و پلی‌رایت می‌خواهد. این‌ها را می‌سنجد:
- پرسش پیش از ورود: کارت «ثبت شد»، فرستاده نشدن پیش از ورود، فرستادن پس از ورود، ماندن پس از بارگذاری دوباره
- مهمان (با `MOCK_GUESTS=1`)، و تمام شدن سهم و پنجرهٔ ثبت‌نام
- ورود پیامکی و ورود با دعوت
- تاریخچه، از جمله تاریخچهٔ مهمان
- بازخورد و حالت تیره
- گوشی ۳۲۰ پیکسلی، تبلت و حالت افقی
- نبودن متن انگلیسی در صفحه

سرور ساختگی جداگانه: `npm run mock`، روی نشانی `http://127.0.0.1:8698`. پیش‌فرضش مثل سرور امروز است: بی‌ورود پرسشی پذیرفته نمی‌شود.
- `MOCK_GUESTS=1`: پرسیدن بی‌ورود (مهمان) هم روشن است.
- `MOCK_LEGACY=1`: مثل سرور پیش از ورود پیامکی، فقط با کد دعوت.
- `MOCK_BUSY=1`: هر پرسش پیام «شلوغ است» می‌گیرد.
- مقدارهای آزمون: کد دعوت `TEST-CODE`، کد پیامک `123456`.

## استقرار

پوشهٔ `out/` به شکل یک بستهٔ فشرده روی اسپارک به جای `src/trial/static_next` می‌نشیند. نمونه: `deploy_guest_ui.sh` در `khaznde_staging/ops/guest-ui/`.

هر مسیر تازهٔ `/api/*` یا پوشهٔ تازهٔ پرونده باید در دروازه هم باز شود. دروازه فقط مسیرهای شناخته را رد می‌کند؛ نمونه‌اش `gateway_next.sh` در `khaznde_staging/ops/site-v2/` است.

## نسخهٔ نمایشی

```
DEMO_BUILD=1 npx next build && node dev/make-demo.mjs   # خروجی: ../tapsareh-site-demo/
```

در نسخهٔ نمایشی پاسخ‌ها را `dev/demo-shim.js` درون مرورگر می‌سازد. هیچ‌کدام از این دو پرونده در ساخت واقعی نیست.
